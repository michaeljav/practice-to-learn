# Web UI Testing - 2

## Instructions (transcribed exactly as given)

1. Set the title of HTML page as **'Web UI Testing - 2'**.
2. In **Section 1**, create a button with the **id "revealButton"**.
3. In **Section 1**, create a **div** with the **id "hiddenContent"** and the class **"hidden"**.
4. Create **Section 2** with:
   - **id="section2"**
   - a heading **"Section 2"**
   - an unordered list containing **three items** with **anchor tags**
     - Item 1
     - Item 2
     - Item 3
5. In **Section 3**, create an HTML **form** with the ID **"sampleForm"** containing:
   - **Name** and **Age** input fields, each with labels and a submit button.
   - The **Name input** should require more than **8 characters**.
   - The **Age input** should be in the range **4 to 99**.
   - Validation will be done in `script.js`.
6. Add IDs and class names to the input tags:
   - Name input: **ID "name"**, **class "name"**, **type "string"**
   - Age input: **ID "age"**, **class "age"**, **type "number"**
7. Include your JavaScript file `script.js` for handling interactions.

## How to run locally

1. Create a folder (for example): `C:\web-ui-testing-2`
2. Inside that folder, add these files:
   - `index.html`
   - `script.js`
   - `styles.css`
3. Open `index.html` in your web browser by double-clicking it.
4. Done! The page will load and you can test the interactions.
